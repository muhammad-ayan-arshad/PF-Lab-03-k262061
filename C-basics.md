 C Programming Basics

1. Data Types
int: Stores whole numbers.
float: Stores decimal numbers with single precision.
double: Stores decimal numbers with higher precision than float.
char: Stores a single character.
bool: Stores either true (1) or false (0).
void: Represents the absence of a value.

2. Format Specifiers
%d: Used for signed integer values.
%u: Used for unsigned integer values.
%o: Used for octal integer values.
%x: Used for hexadecimal values in lowercase.
%X: Used for hexadecimal values in uppercase.
%f: Used for floating-point values.
%e: Used for scientific notation.
%c: Used for characters.
%s: Used for strings.
%ld: Used for long signed integer values.

 3. Input/Output Functions
scanf(): Used to read formatted input from the user.
printf(): Used to display formatted output on the screen.
getchar(): Used to read a single character from the user.
putchar(): Used to display a single character.
fgets(): Used to read a line of text from the user.
puts(): Used to display a string followed by a new line.

4. Escape Sequences
\n: Inserts a new line.
\t: Inserts a tab.
\b: Inserts a backspace.
\r: Inserts a carriage return.
$$: Inserts a backslash.

 5. Precision
Precision: Precision specifies the number of digits displayed after the decimal point for
floating-point values. It is specified by using a period followed by the desired number of digits in the format specifier

Example: %.2f displays a floating-point value with 2 digits after the decimal point.
